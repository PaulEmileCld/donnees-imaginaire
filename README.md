# Données de l'imaginaire

Collecte des associations libres de JeuxDeMots (LIRMM, données CC0) autour des mots de Gilbert Durand, pour la cartographie de l'imaginaire.

- `collecte/mots_durand.txt` : liste des mots de départ.
- `reperage/` : premier passage, qui lit la description des fichiers disponibles.
